## The situation

You need to hire **~50 people in ~2 months**. That is not “run a few more interviews.” It is a throughput problem:

| Constraint | What breaks without a new approach |
|------------|------------------------------------|
| **Volume** | 50 hires ≈ hundreds of screened candidates if conversion is normal |
| **Time** | 8 weeks leaves almost no room for multi-week take-homes and panel loops on every person |
| **Signal** | AI-assisted applications and polished take-homes look “senior” without proving judgment under real work |
| **Fairness & consistency** | Different interviewers, different bars → noise, bias, and rework |

**Wedge:** (1) **Early self-service screening** that scores role fit at volume, and (2) an **self-service take-home** that is economical for high-volume roles *and* cheaper to run on high-profile ones.

## Two products for this campaign

| Product | One line | Inputs | Full brief |
|---------|----------|--------|------------|
| **Self-Service Skill Check** | ~15 min private link, think-out-loud dialog → role ranking + per-candidate strengths/weaknesses; **API automation available** | **JD (req.)** + culture / hiring brief (opt.) | [product-early-self-service-screening.md](./product-early-self-service-screening.md) |
| **Self-Service Take-Home** | Multi-block open-ended work sample → same ranking + per-applicant report; viable at volume or cheaper on premium roles | Screening signals (opt.) + exercise description (rec., or **we design it**) | [product-self-service-take-home-assignment.md](./product-self-service-take-home-assignment.md) |

---

## Shared outputs (both products)

| Deliverable | Description |
|-------------|-------------|
| **Role / job-position report** | Ranked list of candidates against **role performance**, not a generic quiz score. |
| **Per-candidate report** | Strengths, weaknesses, and structured signal for humans — and for **downstream stages** (interview guides, calibration, offer risk). |
| **One bar per role family** | Same workspace markers for every applicant in the campaign. |

---

## Suggested funnel (illustrative)

```
Apply → (optional) resume/screen
     → Self-Service Skill Check (~15 min)   ← volume + early signal
     → HM / tech interview                      ← only strong ranks
     → Self-Service Take-Home (multi-block)       ← depth / work sample
     → Offer
```

Use **only Card 1** when speed is everything; **Card 1 + Card 2** when you need both throughput and a serious work sample; **Card 2 alone** when the role already passes a light screen but take-home cost is the bottleneck.

## Pilot (2–4 weeks)

1. Pick **1–2 high-volume roles** in the 50-hire plan.  
2. Stand up **Self-Service Skill Check** (15-min link + role ranking).  
3. Optionally add **Self-Service Take-Home** for finalists or for one premium track.  
4. Calibrate pass/fail on the first N reports with hiring managers.  
5. Roll the same products across the rest of the ramp.

**Success metrics:** time-to-first-signal, % advanced to HM interview, reviewer hours saved, quality of shortlist vs. prior process.
